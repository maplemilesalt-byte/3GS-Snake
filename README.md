# 3GS Snake

A native Snake game for iPhone 3GS / iOS 6.2.6, written in Objective-C with Theos.

Build with `make package`. Swipe to turn; tap after game over to restart.

`Resources/snake-sprites.png` is a transparent 224×64 sprite sheet: head, body, food (three 64×64 tiles with transparent spacing). The app loads the PNG sprites from its bundle.
